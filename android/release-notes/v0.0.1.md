## UZDoomDroid 0.0.1

The first test build of a controller-only Android port of [UZDoom](https://github.com/UZDoom/UZDoom).
Based on UZDoom commit [`678ed12`](https://github.com/UZDoom/UZDoom/commit/678ed12027fec6257a08bfcdbabba06bfcebf8de).

**Requirements:** Android 8.0+, 64-bit ARM, OpenGL ES 2.0+ (3.x recommended), a game controller.
**No game data included.** Bring your own IWAD (e.g. `doom2.wad`) or use the free [Freedoom](https://freedoom.github.io/).

### Install

1. Download `UZDoomDroid-v0.0.1.apk` below and open it on your device. Allow installs from that app when Android asks.
2. Open **UZDoomDroid**, connect a controller, press **Y** to import your `.wad`, then press **START**.

### What's in it

- A gamepad-only launcher for choosing a game, mods and file import, plus a licenses screen (**SELECT**)
- OpenGL ES renderer and the software renderer
- Menus sized for small screens (adjust in *HUD Options → Scaling Options → Menu text scale*)
- Jump and freelook off by default (*Gameplay Options*)

### Known limitations

- Vulkan is disabled. VP8/VP9 cutscene videos don't play.
- OGG/FLAC/MP3 music in mods doesn't play yet. MIDI, tracker music and the standard sounds do.
- Tested on one device only.
- The APK is signed with a temporary build key. A later version may not install over this one; if so, uninstall this
  version first. Back up `Android/data/io.github.morganhowe.uzdoomdroid/files/` to keep your saves.
