## UZDoomDroid 0.1.1

A smaller update to the controller-only Android port of [UZDoom](https://github.com/UZDoom/UZDoom): better performance and a couple of conveniences.
Based on UZDoom commit [`678ed12`](https://github.com/UZDoom/UZDoom/commit/678ed12027fec6257a08bfcdbabba06bfcebf8de).

Installs over 0.1.0 and keeps your games, saves and settings.

### Faster

- **Optimised engine build.** The engine is now compiled as a proper release build (no internal debug checks) with link-time optimization.
- **Android performance hints** (Android 13+). The game tells Android how long each frame should take, so the CPU speeds up in time and the game stays on the fast cores. Fewer dips, especially in power-saving performance modes.
- **Texture precaching** is on by default, so big levels don't hitch when new areas first come into view. Levels take a moment longer to load. Your current setting is switched to this once.

### New

- **Show FPS** in *Options → Display Options*.
- **On-screen keyboard for the console.** Android's keyboard opens with the console (bind *Open Console* under *Customize Controls → Other*), and the game no longer squashes itself to make room for it.

### Requirements

Android 8.0+, 64-bit ARM, a game controller. A Vulkan-capable GPU is recommended (OpenGL ES 2.0+ otherwise).
**No game data included.** Bring your own IWAD (e.g. `doom2.wad`) or use the free [Freedoom](https://freedoom.github.io/).

### Known limitations

- VP8/VP9 cutscene videos don't play.
- Tested on two devices (a Retroid Pocket Nova and an AYN Thor).
